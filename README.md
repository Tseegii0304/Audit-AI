# 🛡️ Audit AI 

**Аудитын илрүүлэлтийн эрсдэлийг бууруулах хиймэл оюун, машин сургалтад суурилсан интерактив веб шийдэл**

> Санхүүгийн тайлангийн аудит дахь илрүүлэлтийн эрсдэлийг (Detection Risk = 1 − Recall) бууруулах
> зорилгоор боловсруулсан, тайлбарлагдах хиймэл оюун (XAI)-д суурилсан, аудитын олон улсын
> стандарт (АОУС/ISA)-тай уялдсан дөрвөн давхаргат загварын практик хэрэгжилт.

## 📋 Тойм / Overview

Audit AI нь аудитын өгөгдлийг уншиж цэгцлэхээс эхлээд эрсдэлийн оноо тогтоох, аудиторт ойлгомжтой
тайлбар гаргах хүртэлх үйл явцыг **дөрвөн давхаргат бүтэц** болгон зохион байгуулсан Streamlit веб
систем юм. Давхарга бүр бие даан ажиллах боломжтой тул байгууллагын бэлэн байдлын түвшинд тааруулан
үе шаттай нэвтрүүлэх давуу талтай.

| Давхарга | Зорилго | АОУС |
|---|---|---|
| 1. Өгөгдөл бэлтгэл | Гүйлгээний баланс / Ерөнхий журналын автомат хөрвүүлэлт, цэвэрлэгээ | ISA 300 |
| 2. Нэгдсэн илрүүлэлт (хяналтгүй) | Isolation Forest, Бенфордын хууль, олон загварын санал хураалт | ISA 240, 315 |
| 3. Хяналттай ангилал | Random Forest / Gradient Boosting / Logistic Regression, 5-fold CV, temporal validation | ISA 200, 530 |
| 4. Тайлбарлагдах ХОУ (XAI) | SHAP шинж чанарын ач холбогдол, АОУС стандартын лавлагаа | ISA 315, 520 |

## ✨ Үндсэн боломжууд

- **15 модуль**: Өгөгдөл оруулах, Дашбоард, Гүйлгээний балансын шинжилгээ, Ерөнхий журналын
  шинжилгээ, Материаллаг байдал (ISA 320), Салбарын шинжилгээ, Сургалт/Шалгалт, Нарийвчилсан
  машин сургалт (McNemar, Learning curve, Hyperparameter, Sensitivity), Диссертацийн гаралт,
  болон төрийн аудитын 6 тусгай модуль (мөнгөн гүйлгээ, ЭЗ ангилал, хуулийн зөрчил, зардлын
  ангилал, ISA 550 харилцагч, эрсдэлийн нэгтгэл).
- **Автомат файл таних**: ГҮЙЛГЭЭ_БАЛАНС → raw_tb, ЕРӨНХИЙ_ЖУРНАЛ → edt,
  ХАРИЛЦАХЫН_ХУУЛГА → cash, зардлын ангилал → expense_class (.xlsx/.xls/.xlsm/.xlsb/.csv/.tsv/.gz).
- **55+ интерактив Plotly график**, ROC муруй, эрсдэлийн матриц, чиг хандлага.
- **Илрүүлэлтийн эрсдэлийн харьцуулалт**: AI загвар ↔ Мөнгөн дүнд суурилсан түүвэрлэлт (MUS).

## 🚀 Локал орчинд ажиллуулах

```bash
git clone https://github.com/<таны-хэрэглэгч>/audit-ai-prototype.git
cd audit-ai-prototype
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run audit_ai.py
```

Браузер автоматаар `http://localhost:8501` хаягаар нээгдэнэ. Зүүн талын цэснээс модуль сонгож,
`1️⃣ Өгөгдөл оруулах` хэсэгт өөрийн Excel файлуудаа байршуулна.

## ☁️ Streamlit Community Cloud дээр байршуулах

1. Энэ репозиторийг өөрийн GitHub account руу push хийнэ.
2. [share.streamlit.io](https://share.streamlit.io) → **New app** → энэ репог сонгоно.
3. **Main file path**: `audit_ai.py` → **Deploy**.

`runtime.txt` (Python 3.12), `requirements.txt`, `.streamlit/config.toml` нь Cloud дээр
автоматаар уншигдана. Нэмэлт тохиргоо шаардлагагүй.
